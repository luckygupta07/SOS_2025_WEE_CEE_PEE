# Summer of Code (WEE CEE PEE)

In this project, I have learnt about competitive programming along with some data structures and algorithms, and I have focused more on applications than theory. 
My Codeforces accounts are :-  [_yorichi_](https://codeforces.com/profile/_yorichi_) and [7ucky](https://codeforces.com/profile/7ucky).
In this repository, every file consists of a problem or a demonstration of an algorithm. 
Each file containing a problem, consists of the code of the solution and the problem link at the header.

I have completed this project in a structured manner with the order of topics as follows:

## Week 1
- Learnt the basics of competitive programming.
- Learnt about sorting and searching, prefix sums, binary search and two pointers approach.

## Week 2 and 3
- Learnt greedy and basics of dynamic programming.
- Learnt the integration of combinatorics and dynamic programming and solved practice problems.
- Learnt advanced dynamic programming along with regret greedy approach.

## Week 4
- Learnt graph and tree traversal algorithms.
- Learnt applications of traversal algorithms to solve some basic problems related to graphs.

## Week 5
- Learnt advanced graph algorithms like detection of cycle in DAG, topological sort, Dijkstra, Floyd Warshall, Bellman Ford, Floyd's cycle finding algorithm, Kruskal and Prim's algorithm to find minimum spanning tree, etc.
- Solved dynamic programming problems involving the aforementioned algorithms.
